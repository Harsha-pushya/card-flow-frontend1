# card-flow-frontend1
 Project Highlight: CardFlow – Credit Card Management System
I’m currently working on CardFlow, a simple yet powerful credit card management system designed to help me master frontend development skills.

 Key Focus Areas:

HTML → Clean, semantic structure for accessibility and scalability

CSS → Beautiful, modern styling with gradients, glassmorphism, and responsive layouts

JavaScript → Interactive features like dynamic card creation, validation, and smooth user experience

Why this project?
CardFlow is my way of combining design + functionality to strengthen my frontend fundamentals while building something practical and visually appealing.
